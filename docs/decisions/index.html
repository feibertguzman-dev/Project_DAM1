ADR-001: Kotlin y Jetpack Compose

Estado: Aceptado | Fecha: 2025-01-01

Contexto

Se requiere una app Android moderna, reactiva y con UI nativa para múltiples roles.

Decisión

Usar Kotlin como lenguaje y Jetpack Compose para la interfaz declarativa con Material 3.

Alternativas Rechazadas

  • Java + XML Layouts
  • Flutter
  • Kotlin Multiplatform

Consecuencias

  • Código conciso y mantenible
  • UI reactiva y moderna
  • Mejor integración con APIs Android
  • Curva inicial con paradigma declarativo

ADR-002: Firebase como Backend

Estado: Aceptado | Fecha: 2025-01-02

Contexto

Se necesita autenticación, base de datos en tiempo real y seguridad sin infraestructura propia.

Decisión

Usar Firebase Authentication, Cloud Firestore, Firebase App Check y Google Identity Services.

Alternativas Rechazadas

  • Backend propio (REST)
  • Supabase
  • AWS Amplify

Consecuencias

  • Desarrollo ágil
  • Sincronización en tiempo real
  • Autenticación robusta
  • Dependencia del ecosistema Firebase

ADR-003: Google Gemini AI para Resúmenes

Estado: Aceptado | Fecha: 2025-01-03

Contexto

Necesidad de generar resúmenes automáticos para apoyar el estudio de los estudiantes.

Decisión

Integrar Google Gemini AI mediante Firebase AI SDK.

Alternativas Rechazadas

  • OpenAI GPT
  • Anthropic Claude
  • Modelos locales

Consecuencias

  • Resúmenes automáticos con IA
  • Integración nativa con Firebase
  • Requiere conexión a internet
  • Uso de API gestionado con Secrets Gradle Plugin
